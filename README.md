# LabFlow

LabFlow is a Python prototype exploring how natural-language instructions can be translated into validated laboratory workflows.

## Project goals

- Convert natural-language liquid-handling instructions into structured data.
- Validate instructions against predefined rules.
- Simulate liquid transfers without controlling physical laboratory equipment.
- Evaluate the reliability and limitations of the approach.

## Status

Early development. The validation logic is being developed before integrating a real large language model (LLM).

## Scope and safety

LabFlow is an educational prototype. It does not control real laboratory instruments, and simulated instructions must not be treated as validated laboratory procedures.
